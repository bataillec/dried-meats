# Changelog

## 0.2.1 (2026-11-27)

- Leaving the vacuum stage from the notification now asks for the fridge seasoning (R8, R13).

## 0.2.0 (2026-11-23)

- Ko-fi and GitHub support links (R29).
- Accent colour is user-selectable (R27).
- One time picker for the reminder time in Réglages (issue #7).
- Meat type is decoupled from the recipe (issue #5).
- Removed the open-in-calculator button from the piece detail (issue #9).
- Removed the "Calculateur" tab and the standalone calculator screen (issue #10, R5 dropped). Doses are
  still shown live when creating a piece (R4) and kept on the piece.
- Recipe form: the "Durée du sous-vide" section shows the formula with the typed values and a live
  6 cm example (R28). The Réglages example now uses 6 cm too (was 9 cm).

## 0.1.0 (2026-11-22)

- Dose calculator, recipes and meat types, pieces with vacuum and fridge stages, reminders with
  "Fait" / "Reporter 1 jour", overdue pinning, statistics, JSON export/import, calendar hand-off,
  themes Clair / Sombre / OLED / Système.
